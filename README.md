# 屍城戰線（暫定名）

用 OpenStreetMap 真實街道做戰場嘅末世喪屍遊戲。完整計劃睇 [PLAN.md](PLAN.md)。

- 網址（開咗 GitHub Pages 之後）：https://fiveathree.github.io/OpenStreetZombie/
- 而家做到 PLAN.md 第 1 至 4 階段：安全屋、小地圖、兩個中地圖街區、大地圖。

## 流程

標題 → **安全屋**（揀隊、升級、醫傷、招募）→ 揀地圖出擊 → 結算（資源、經驗、碎片、傷勢）→ 返安全屋。

| 地圖 | 玩法 | 解鎖 |
|---|---|---|
| 小地圖：街道衝鋒 | 每日一條真實大街（由 OSM 揀最長嗰幾條，每日輪換）。小隊自動向前衝，左右揀行邊邊過門。喪屍一排排湧過嚟、由騎樓伏擊、由真實橫街湧出；有大隻佬同街尾屍王。「＋」「−」門可以射（數字會升，−門射到變 +）；路上有油桶（射爆炸埋附近啲屍）、物資箱（加兵／升武器／充滿大招）、困住嘅倖存者（加兵，有時係屍城日誌角色）。殺屍充大招，大路口即刻充滿。1–2 分鐘。 | 一開始就有 |
| 中地圖：鹽埕街區 | 白天，撐 5 分鐘；藥房補血、便利店能量飲品、尖叫屍、屍潮、屍王、救倖存者。 | 一開始就有 |
| 中地圖：七賢路街區 | 夜晚（手電筒光錐），難啲；有七賢路派出所（武器）同台灣中油（可以引爆）。 | 過咗鹽埕 |
| 大地圖：愛河大戰 | MOBA（PvE）：三路經愛河上嘅七賢橋、中正橋、高雄橋；箭塔、兵營、野區（精英屍、物資、被困倖存者）、野區 Boss、喪屍王揀最弱嗰路攻；派隊友或者守備小隊守點；日夜交替。打爆巢穴贏，主城失守輸。 | 兩個街區都過咗 |

安全屋右下角有「全部解鎖（試玩用）」，即刻開晒所有地圖同隊友，資源加到 300。

| 攻擊 | 自動 | 自動 |
| 大招 | 空白鍵或者 Q | 撳「大招」（充滿先用得） |
| 指揮（中地圖） | 1 跟我、2 散開、3 守住、4 集火 | 右下角四個掣 |
| 指揮（大地圖） | 1 推上路、2 推中路、3 推下路、4 守主城、5 集合、6 打 Boss；B 回城 | 右下角掣 |
| 派個別隊友（大地圖） | 撳左上角隊友個名揀佢（有白框），再撳指揮掣、撳地圖或者撳小地圖：淨係派佢去；撳建築就派佢守嗰度。再撳個名取消 | 同左 |
| 睇第度（大地圖） | 撳或者拖左下角小地圖，鏡頭就去嗰度；一郁或者撳「返去自己度」就返嚟 | 同左 |
| 派人守點（大地圖） | 撳建築或者撳左下角小地圖上嘅建築 | 同左 |

| 揀隊長（小地圖） | 1 2 3 | 撳下面隊長：門嘅效果加落嗰隊 |
| 拉近／拉遠 | 滑鼠轆、＋／－ 鍵、右邊 ＋ － | 兩隻手指捏、右邊 ＋ － |

## 屍城日誌角色聯動

屍城日誌（`fiveathree/zomibee`）嘅 131 個角色抄咗入嚟（`data/zomibee-cast.json`），按佢哋 7 項數值（力量、敏捷、感知、技術、醫術、廚藝、意志）分做 5 個戰鬥職業，血、傷害、速度都跟數值行；貓狗用咬。

- **點樣得到**：中地圖同大地圖嘅被困倖存者、小地圖嘅籠同街尾倖存者，全部都係屍城日誌角色。救到就有佢嘅專屬碎片；按稀有度（C 50%～UR 20%）有機會**即刻加入幫手**（每局最多 2 個）。加入咗又捱到最後，就正式入隊。
- **招募**：專屬碎片夠數就招募（C 2、R 3、SR 4、SSR 6、UR 10）；唔夠可以用通用碎片補。
- **陣營羈絆**：同陣營兩人或以上（例如軍警消防：阿坤＋沈默），全隊傷害同血量 +8%（最多兩個陣營）。
- 重新匯入：`node tools/import-zomibee.mjs <zomibee 資料夾>`。

## 隊伍

| 職業 | 隊友 | 攻擊 | 大招 | 小地圖帶嘅兵 |
|---|---|---|---|---|
| 坦克 | 阿坤（消防員） | 推開身邊喪屍 | 嘲諷：附近喪屍轉打佢、減傷 | 盾兵 |
| 醫療 | 小芳（護士） | 手槍＋補血、救人快一倍 | 急救站：全隊回血、救起倒地 | 救護兵（慢慢補人） |
| 輸出 | 阿傑（退伍軍人） | 步槍，穿透 | 掃射：射速三倍 | 機槍兵 |
| 控場 | 陳老師（化學老師） | 火焰噴射，燒同減慢 | 汽油彈：一片火 | 火焰兵 |
| 支援 | 阿明（外送員） | 狙擊，專打最硬嘅 | 物資空投：全隊傷害同移速 +30% | 狙擊兵 |

- 一開始有坦克、醫療、輸出；控場同支援要用通用碎片招募（跑完小地圖、大地圖贏都有通用碎片）。
- **羈絆**：消防員＋化學老師＝火海加倍；護士＋退伍軍人＝戰地醫護；消防員＋外送員＝救援隊；化學老師＋外送員＝土製炸彈。
- **組合技**：喺汽油彈火區入面掟手榴彈 ＝「火海」（火區變大、傷害更高、燒耐啲）。
- **成長**：每場帶返經驗；經驗夠就用食物同藥品升級（每級 +10% 血同傷害）；3 級學識大招強化。
- **傷勢**：陣亡嘅隊友下一場受傷（血 −30%）；抖一場就好返，或者用藥品即刻醫。
- 存檔喺瀏覽器 localStorage（同一部機、同一個瀏覽器先有效）。

## 地點效果（真實 OSM 地點）

| 地點 | 效果 |
|---|---|
| 藥房、診所 ✚ | 企入圈補血（藥用完要等） |
| 便利店、超市 | 能量飲品：全隊射速 +30%，20 秒 |
| 警局 | 武器：全隊傷害 +40%，30 秒 |

## 喺自己部機開

遊戲用 ES modules 同 `fetch` 讀地圖，要經網頁伺服器開，唔可以直接雙擊 `index.html`：

```bash
npx http-server -c-1
```

然後開 http://localhost:8080 。

## 發佈（GitHub Pages）

repo 頂部 **Settings → Pages → Build and deployment**：Source 揀 **Deploy from a branch**，Branch 揀 `main`、資料夾揀 `/ (root)`。唔使建置。

## 重新下載地圖

```bash
node tools/fetch-osm.mjs 22.6244 120.2838 200 data/yancheng.json 高雄鹽埕區
```

```bash
node tools/fetch-osm.mjs 22.6289 120.2840 220 data/qixian.json 鹽埕七賢路
```

```bash
node tools/fetch-osm.mjs 22.6262 120.2858 760 data/big.json 鹽埕・愛河 --big
```

OSM 喺台灣嘅建築輪廓唔齊，所以遊戲當「道路、空地同河以外」全部都係密集街屋（障礙物、擋子彈）。

## 重整分享圖

開住本機伺服器，然後用 Edge 或者 Chrome 無頭模式截圖：

```bash
msedge --headless=new --hide-scrollbars --window-size=1200,630 --virtual-time-budget=30000 --screenshot=og.png http://localhost:8080/tools/og.html
```

## 技術

- 同截蛇大亂鬥（`fiveathree/snake`）一樣：純 HTML + Canvas 2D + JavaScript，空間網格做碰撞，鏡頭跟人，冇用框架、唔使建置。
- 喪屍尋路用共用流場圖（BFS），唔係每隻屍自己計路；大地圖地圖分塊，只畫睇得到嗰幾塊。
- 地圖用瀏覽器 canvas 光柵化同畫；唔用 OSM 官方地圖圖塊。
- 字型：Google Fonts 嘅 Noto Sans TC 同 IBM Plex Mono。
